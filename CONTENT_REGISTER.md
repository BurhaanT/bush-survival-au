# Content and claim register

**Purpose:** Control the evidence and approval status of every factual or instructional unit before it enters the usable book.  
**Gate:** [CONTENT_VALIDATION_GATE.md](CONTENT_VALIDATION_GATE.md)

## Register fields

| Field | Required information |
|---|---|
| Content ID | Stable identifier, e.g. `COMMS-001` or `PLANT-012`. |
| Chapter/section | Canonical Markdown location. |
| Claim or instruction | One auditable proposition or coherent instruction set. |
| Consequence level | 1, 2 or 3. |
| Intended action | What the reader may do because of it. |
| Victoria scope | Region, season, land context and exceptions. |
| Source IDs | Independent sources recorded in `SOURCE_REGISTER.md`. |
| Contradiction search | Where and how contrary evidence was sought; result. |
| Visual IDs | Images/diagrams that affect meaning. |
| Test/reviewer | Usability/field test and human specialist sign-off. |
| Currentness trigger | Date/event that requires rechecking. |
| Status | Proposed through Approved/Rejected/Superseded. |
| Decision note | Why it was accepted, restricted or rejected. |
